Apps

Apps I make for Apple Vision Pro, iPhone, iPad and Mac. They aren't on the App Store yet. The iPhone and iPad builds install through AltStore or SideStore from apps.illixion.com.

  • Convolution

    Photo, video and film library

    One library for your Photos, a Stash, Nextcloud or Jellyfin server, or local files. Films keep their object audio, and on Vision Pro it turns flat photos and videos into 3D.

    Vision Pro, iPhone, iPad, Apple TV and Mac

    Source on GitHub

  • Longwave

    Remote desktop and game streaming

    VNC remote desktop, game streaming from a Sunshine host and an SSH terminal for the computers you own. On Vision Pro the desktops sit in the room as windows you place.

    Vision Pro, iPhone, iPad and Mac

    Website Source on GitHub

  • Worldcast

    Podcast listener for one person

    A small Node.js server you run keeps your subscriptions and progress. A web app and the Apple clients play from it.

    iPhone, iPad, Apple Watch, Vision Pro and the web

    Source on GitHub
